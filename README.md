# Formación de Programación para Dummies

Un proyecto educativo interactivo diseñado para aprender programación desde cero de forma práctica y divertida.

## 📚 Conceptos Cubiertos

- **Variables y Tipos de Datos**: Los fundamentos del almacenamiento de información
- **Operadores**: Operaciones aritméticas, lógicas y de comparación
- **Estructuras de Control**: Tomar decisiones con if, else y switch
- **Bucles**: Repetir acciones con for, while y otros
- **Funciones**: Crear código reutilizable
- **Arrays y Objetos**: Organizar datos complejos
- **DOM y Eventos**: Interactuar con el navegador
- **Asincronía**: Manejar operaciones asincrónicas

## 🚀 Instalación

1. Clona este repositorio
2. Instala las dependencias:
   ```bash
   npm install
   ```

3. Inicia el servidor de desarrollo:
   ```bash
   npm run dev
   ```

La aplicación se abrirá automáticamente en http://localhost:3000

## 📦 Tecnologías

- **React 18**: Librería JavaScript para interfaces de usuario
- **Vite**: Herramienta de construcción rápida
- **CSS3**: Estilos modernos y responsivos
